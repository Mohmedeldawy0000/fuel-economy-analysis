# fuel-economy-analysis
# Car Fuel Economy Analysis (2008 vs 2018)

## Overview
This project analyzes car fuel economy data from 2008 and 2018 using Python to compare efficiency, emissions, and vehicle features.

## Tools Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Jupyter Notebook

## Key Results
- Average fuel economy (MPG) increased from 19.79 in 2008 to 23.57 in 2018.
- Strong relationship between engine size and fuel efficiency.
